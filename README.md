## Configuración

Antes de ejecutar el proyecto, configure el archivo:

```text
SistemaAlquiler-backend/src/main/resources/application.properties
```

Reemplace los siguientes valores por los correspondientes a su entorno.

### Base de datos (SQL Server)

```properties
spring.datasource.username=TU_USUARIO
spring.datasource.password=TU_PASSWORD
```

### Correo electrónico (SMTP)

```properties
spring.mail.username=TU_USUARIO_DE_CORREO
spring.mail.password=TU_PASSWORD_DE_CORREO
```

### API de Culqi

```properties
culqi.public.key=TU_CLAVE_PUBLICA
culqi.secret.key=TU_CLAVE_SECRETA
```
